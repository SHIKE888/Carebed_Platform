# CareBed 前端演示（Vue 版本）

该示例为轻量级的 Vue 3 单页应用，旨在快速验证后端接口交互。无需构建工具，仅依赖 CDN。

## 目录结构

```
前端/
├── index.html      # 主入口页面，包含 Vue 应用逻辑
└── README.md       # 使用说明
```

## 运行方式

1. 确保后端服务已在本地 `http://localhost:8081` 运行。
2. 在前端目录启动任意静态服务器，如：
   ```bash
   cd 前端
   npx serve .
   # 或使用 python
   python -m http.server 5173
   ```
3. 浏览器访问对应地址（例如 `http://localhost:3000` 或 `http://localhost:5173`）。

> 直接双击打开 `index.html` 亦可演示，但部分浏览器会拦截本地文件发起的跨域请求，建议通过本地服务托管。

## 功能概览

- **统一登录**：单一登录/注册入口，按角色自动切换客户门户或管理后台。
- **客户门户**：
   - 设备状态浏览、快速租借、归还/取消操作。
   - 钱包余额、充值、交易明细及争议提交。
   - 报修提报与进度跟踪。
   - 通知中心支持未读筛选与标记已读。
- **管理后台**：
   - 运营总览与趋势分析面板。
   - 设备登记、信息维护、绑定/解绑、故障、心跳等运维动作。
   - 租借订单管理、费用争议审核、维修工单处理。
   - 用户列表与管理员通知查看。
- **日志面板**：实时记录所有 API 请求，便于调试定位。

## 自定义配置

- 若后端端口或地址调整，可修改 `index.html` 顶部脚本中的 `apiBase` 常量。

所有交互基于内存实现的后端服务，适合做完整业务流程演示。
