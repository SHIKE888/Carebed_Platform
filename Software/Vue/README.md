# CareBed 前端演示（Vue 版本）

轻量级 Vue 3 单页应用，用于验证后端接口与业务流程。无需构建工具，直接通过浏览器或任何静态服务器运行。

## 目录结构

```
Vue/
├── index.html   # 主入口页面，包含所有脚本
└── README.md
```

## 运行方式

1. 确保后端服务可访问（默认 `http://localhost:8081`）。
2. 在 `Vue` 目录启动任意静态服务器，例如：
   ```bash
   cd Vue
   npx serve .          # 或 python -m http.server 5173
   ```
   然后在浏览器访问对应地址（如 `http://localhost:3000` 或 `http://localhost:5173`）。
3. 也可直接双击打开 `index.html`，但部分浏览器会限制本地文件发起的跨域请求，推荐通过本地服务。

## 功能概览

- 登录/注册后按角色切换客户门户或管理后台。
- 客户门户：设备状态浏览、租借/归还、钱包充值与交易、报修提报、通知查看。
- 管理后台：设备运维、租借订单与争议处理、维修工单、用户与通知查看。
- 调试友好：内置请求日志面板，便于观察接口返回。

## 配置

- 页面顶部脚本中的 `apiBase` 控制后端地址和端口，部署时请按环境修改。
